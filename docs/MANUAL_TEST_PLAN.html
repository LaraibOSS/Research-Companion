1 Before you start

Run the app

cd <repo root>
pip install -e ".[server]"
research-companion lab serve        # http://127.0.0.1:8765

If that port is taken, use --port 8800 and adjust the URLs below.

Configure it

SettingWhy it mattersNeeded for
Provider + API key (Anthropic or OpenAI)Powers every AI feature§3, §6, §7, §10
Contact emailRaises the OpenAlex rate limit (“polite pool”)§4 — fewer failures
Semantic Scholar API key
free from semanticscholar.org/product/api		Raises the Semantic Scholar rate limit substantially§4 — fewer failures

Without an AI key the deterministic features (§2, §5, §8, §9, §11) still work. AI features will report a missing model rather than crashing — that is correct behavior, not a bug.

Two test workspaces

Several tests need a brand-new, empty research. Create one from Researches → + New research (e.g. QA-Empty). Keep a second research that already has papers (e.g. QA-Full) for tests that need data.

Read before filing a bug

Rate limiting is expected. The paper catalogues (Semantic Scholar, OpenAlex) are free, keyless and shared. Adding 20 papers then searching repeatedly will trip a limit. Correct behavior is a plain-language message: “Search is rate-limited right now — the paper catalogues are free and shared, so they throttle bursts. Wait a minute and try again.”

A raw Client error '429 Too Many Requests' for url … is a bug — report it. Once a limit is hit, setting the email or API key does not lift it immediately; the window has to pass.

How to report

For each case record Pass / Fail / Blocked (click the result cell to cycle it), plus the browser console output (F12 → Console) if anything looks broken, and a screenshot for visual issues.

Always a bug

A blank tab, or a red ReferenceError in the console. Report it with the console text — this exact failure has shipped twice before.

13 Known limitations

Do not file these as defects.

  • Rate limiting — expected under bursty use. The settings in §1 reduce but cannot eliminate it, and never lift a limit already hit.
  • Venue recognition is best-effort. The venue knowledge base holds short names (NeurIPS, ACL…). A source reporting only a long form with no acronym won’t be badged. Still worth reporting how often badges appear — see §4.6.
  • AI output can be wrong. Directions, briefs, novelty verdicts, alignments and reports are model-generated. Imperfect content is not a bug. Content presented as verified fact, or a citation pointing at a paper you don’t have, is.
  • Coverage percentages in the Report are a keyword-search heuristic, labelled as such — not ground truth.
